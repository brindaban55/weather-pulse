# 🌤️ WeatherPulse • Live Weather Radar & Forecast

A modern, responsive meteorological web application powered by the Open-Meteo REST & Geocoding APIs with ambient canvas weather effects.

## 🌟 Key Features
- **Global Search & Autocomplete:** Search any city or region worldwide with instant debounced geocoding suggestions.
- **GPS Location Detection:** One-click current location weather retrieval via Geolocation API.
- **Dynamic Ambient Canvas:** Real-time particle simulations (rain drops, snow flakes, or warm sunny ambient particles) based on live WMO weather codes.
- **24-Hour Trend Chart & Slider:** Interactive Chart.js temperature curve and hourly rain probability timeline.
- **7-Day Extended Outlook:** Daily min/max temperature visual progress indicators and weather condition icons.
- **Comprehensive Climate Metrics:** Wind speed & direction with rotating compass needle, UV index risk gauge, atmospheric pressure, cloud cover, and sunrise/sunset cycle progress tracker.
- **Unit Toggle:** Easily switch between Metric (°C, km/h) and Imperial (°F, mph).

## 🚀 Getting Started
Open `index.html` directly in any web browser, or run a local server:
```bash
npx serve .
```
